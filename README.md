# 🌐 Portofolio Web - Alief Nur Arfan

Selamat datang di repositori kode sumber untuk website portofolio pribadi saya. Website ini dirancang untuk menampilkan profil, keahlian, pengalaman, serta kumpulan proyek yang pernah saya kerjakan secara interaktif dan responsif.

🚀 **Live Demo / Website:**  
👉 **[https://aliefnarfan.github.io/Portofolio-Alief-Nur-Arfan/](https://aliefnarfan.github.io/Portofolio-Alief-Nur-Arfan/)**

---

## ✨ Fitur Utama

- **Desain Responsif:** Tampilan yang menyesuaikan dengan baik di berbagai ukuran layar (Desktop, Tablet, maupun Mobile).
- **Profil & Unduh CV:** Informasi lengkap mengenai latar belakang profesional beserta fitur untuk mengunduh Curriculum Vitae (`cv_alief.pdf`) secara langsung.
- **Galeri Proyek Interaktif:** Menampilkan berbagai proyek unggulan lengkap dengan dokumentasi visual/tangkapan layar (`project0` hingga `project3`).
- **Navigasi Halus & Interaktif:** Menggunakan JavaScript kustom untuk pengalaman pengguna yang dinamis.

---

## 🛠️ Teknologi yang Digunakan

Proyek ini dibangun menggunakan teknologi web standar yang ringan dan cepat:

- **HTML5** – Struktur semantik halaman web.
- **CSS3** – Styling kustom, tata letak responsif, dan animasi (`css/style.css`).
- **JavaScript (Vanilla JS)** – Interaktivitas halaman dan manipulasi DOM (`js/script.js`).
- **GitHub Pages** – Hosting dan deployment statis.

## 💻 Cara Menjalankan Secara Lokal

Jika Anda ingin menjalankan atau memodifikasi proyek ini di komputer lokal Anda:

1. **Clone repositori ini:**
   ```bash
   git clone https://github.com/aliefnarfan/Portofolio-Alief-Nur-Arfan.git
   ```
2. **Masuk ke direktori proyek:**
   ```bash
   cd Portofolio-Alief-Nur-Arfan
   ```
3. **Buka di browser:**
   Klik dua kali pada file `index.html` atau gunakan ekstensi seperti **Live Server** di Visual Studio Code.
